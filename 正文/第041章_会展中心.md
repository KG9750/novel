# 第041章 会展中心

京北国际会展中心，峰会前一天上午九点。

主论坛还在搭台。

吊车从穹顶下缓慢移动，展架一排排立起来，工人踩着升降台调灯。地面贴着临时导流线，红色通向主论坛，蓝色通向展区，黄色通向医疗服务点。

严存戴着临时顾问证，站在二层看台上。

证件挂在胸前，塑料壳贴着衣服，轻得像假的。

方经理指着下方：“明天八点半开始入场，十点主论坛，十二点闭门会。媒体区在东侧，嘉宾走南门，普通观众走北门。”

严存没有看他说话。

他看人。

保洁车从东侧过，布展工人从西侧抬箱子，礼仪人员排队试走红毯。每个人都在自己的轨道上，暂时不乱。

可备用门禁那枚红点一直压在他脑子里。

“地下物流通道谁管？”他问。

方经理翻平板：“外包安保和会展中心工程部共同管理。你放心，正式活动时不走观众。”

“谁能改权限？”

方经理翻页的手慢了一下：“工程部能提，主办方现场负责人能批，安保只能执行。我们有流程。”

“流程多长？”

“正常半小时，紧急五分钟。”

严存看着下方正在贴地标的工人。

五分钟在普通流程里很短。

在他的世界里，长得像一堵墙。

严存看他：“临时访客批量导入呢？”

方经理脸上的笑僵了一下。

“这个顾队也问过。”他压低声音，“昨晚查了，是系统缓存误触发，已经清掉。”

缓存。

误触发。

这两个词在严存耳朵里都不干净。

顾南枝没出现在现场，她只给了严存一个要求：发现权限异常，不要自行追人，先上传。

严存答应了。

但答应归答应。

他站在二层，看着人流模拟线路，手心还是发潮。

九点五十，主办方做了一次桌面推演。

十几个负责人围在指挥台前，每个人都说自己那一块没有问题。安保说闸机没问题，工程部说门禁没问题，医疗点说医生排班没问题。

严存听得头疼。

他以前在穹图也参加过这种会。

所有单项都没问题，最后事故还是会从缝里钻出来。

上午十点二十，第一次全流程彩排开始。

五百名志愿者从北门入场，按脚本分流到展区和主论坛。大屏上人数、闸机、通道压力实时滚动。

严存盯住北门内侧的临时安检台。

残影里，一个志愿者背包肩带会挂住隔离栏，身体往后带，后排三个人会停步。再后面的人看不见前面停了，会从右侧绕，正好撞上从医疗点出来的推车。

他按下对讲：“北门二号安检台右侧隔离栏建议撤半米，医疗点推车建议改走内侧通道。理由：三秒内会和背包带形成交叉。”

方经理愣了一下，看向指挥室的现场授权表。

现场负责人在表上点了确认。

工作人员执行得很快。

严存没有因为这次成功松气。

他看见方经理在旁边记了一笔，把“严顾问建议”写进彩排记录。

这几个字落在纸上，像一枚很小的钩子。成功时它能抬他，出事时也能挂住他。

一分钟后，背包肩带果然挂了一下。

人没有堵住。

推车也没有撞上。

彩排继续。

指挥室里几个安保负责人交换了一下眼神。

这种眼神严存最近见得多。

怀疑，惊讶，重新估价。

方经理笑着拍了拍他的肩：“明天就按这个节奏来。”

严存没有应。

他想起顾南枝昨晚那张图层。

今天彩排没有媒体直播，没有嘉宾车队，没有线上咨询入口，也没有成千上万人同时看手机。

彩排越顺，明天越容易让人忘了这一点。

严存把这句话记进手机备忘录。

写完又觉得不够，补了一行：

彩排不等于现场。

他保存时，指尖有点发麻。

方经理走过来问他要不要吃盒饭。

严存摇头。

他怕自己一坐下，就会把刚才顺利的几分钟当成答案。

会展中心太大。

大到任何一个角落都可能在他看不见的时候变成入口。

他把饭盒推回去，重新走到看台边。

下方的地贴在灯下很亮。

红、蓝、黄三条线分得清清楚楚。

可人真正跑起来时，从来不会按颜色走。

中午十二点，风险通道弹出提示。

检测到会展中心备用门禁二次访问。

来源：临时访客批量导入。

状态：成功。

严存立刻抬头。

二层看台尽头，一扇原本锁死的灰色门，门禁灯从红变绿。

门后传来很轻的一声响。

像有人在里面，把锁舌推开了。
